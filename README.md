# editor-of-work — паспорт дистанции и схемы ППР

Настольная программа ПТО дистанции инфраструктуры. Она ведёт паспорт дистанции по выгрузкам ЕК АСУИ и по этим данным выпускает годовые документы: схемы планово-предупредительных работ (ППР), схему дистанции и административное деление. Работает без сети, один составитель на своём компьютере, один файл плана на год. Поставляется как переносной exe для Windows; написана на TypeScript (Angular, Electron, SQLite).

**Статус:** разработка, этап 2 — паспорт дистанции. Реализованы каркас приложения и CI, домен планирования, хранение и импорт планов прототипа, SQLite с редакциями, чтение 17 форм выгрузок, сохранение оргструктуры, шести форм характеристик и станционных данных, экран редакций с просмотром и сравнением, выдача и загрузка шаблона ручных данных через интерфейс с предпросмотром и подтверждением. Пользовательские редакторы и выпуск документов ещё разрабатываются; готового exe нет. Рабочим инструментом до завершения этапа 4 остаётся автономный HTML-прототип «Редактор схем ППР». Текущий прогресс — раздел «Этапы разработки» [архитектурного документа](docs/architecture.md).

## Возможности

Ниже — целевые возможности. Доступность отдельных сценариев в коде отражена в [истории изменений](CHANGELOG.md); полный пользовательский цикл ещё не готов.

- **Паспорт дистанции.** Импорт таблиц паспорта из ЕК АСУИ: «веб-страничные» xls, книги xlsx и отчёты BEx. В паспорт входят подразделения и их границы, класс пути, грузонапряжённость, скорости, рельсы, шпалы, балласт, оси станций, экспликации станционных путей и стрелочных переводов, переезды и ОКАТО. Нормативы, пары поездов по участкам и длины нестандартных километров заносятся вручную или через шаблон Excel, который выдаёт программа. Данные хранятся по редакциям: годовой план ссылается на редакцию и через несколько лет откроется с теми же данными.
- **Схемы ППР на год.** Работы привязываются к «км + пк» или к пути и стрелке станции. Программа строит листы А3: общую схему, листы линейных участков (ПД) и листы станций, а таблицы планов с долями по ПД считает сама. Листы сохраняются в PDF сразу файлом, без окна печати.
- **Путевое развитие станций.** Схема строится по таблице путей и стрелок и правится мышью.
- **Схема дистанции** в трёх вариантах оформления: линейная в масштабе, топологическая и схема-таблица.
- **Административное деление**: книга xlsx с формулами, которая открывается в Excel 2007.

Программа не заменяет ЕК АСУИ и не передаёт в неё данные.

## Начать работу

**Составителю:** готового exe пока нет. После выпуска 1.0 он появится в Releases вместе с контрольной суммой SHA-256. Программу достаточно скопировать в папку или на флешку: база паспорта создаётся в папке `data` рядом с exe.

**Разработчику:** понадобятся Git и Node.js 24 LTS. Каркас Nx и Electron уже доступен; `npm start` открывает начальный экран приложения.

```bash
git clone https://github.com/hhypest/editor-of-work.git
cd editor-of-work
npm ci
npm start          # программа в режиме разработки
npm run check      # всё, что проверяет CI
```

Остальные команды, сборка exe и устройство репозитория описаны в [правилах разработки](CONTRIBUTING.md).

## Данные и права

Выгрузки ЕК АСУИ, база паспорта `passport.sqlite`, файлы планов `*.ppr.json` и PDF листов — служебные материалы ОАО «РЖД», в некоторых из них есть ФИО работников. Всё это хранится только на компьютере составителя (в разработке — в папке `private-data/`) и в репозиторий не попадает. Тесты работают на вымышленных данных, которые генерирует скрипт.

База и файлы планов не шифруются: доступ к ним ограничивается средствами ОС и правилами организации.
