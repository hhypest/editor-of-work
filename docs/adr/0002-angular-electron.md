# ADR-0002. Angular + Electron, переносной exe

**Статус:** принято · **Дата:** 20.10.2026

## Контекст

Рабочие ПК — Windows 10/11 x64, без прав администратора и без интернета. Нужен один exe без установки, запуск с диска или флешки, PDF без окна печати и доступ к SQLite. Проект editor-of-tod того же автора написан на TypeScript; хотелось одного семейства стека.

## Решение

- **Electron** — рантайм и поставка: свой Chromium (не зависит от WebView2 на ПК), `printToPDF`, системные диалоги, Node для SQLite и ExcelJS. Сборка — electron-builder, цель `portable`.
- **Angular** (standalone-компоненты, signals) — интерфейс. Встроенный DI и `InjectionToken` естественно ложатся на порты Clean Architecture; реактивные формы удобны для множества справочных форм.
- Процессы: main (диск, SQLite, xlsx, PDF), preload (один объект `window.eow`), renderer (Angular + домен + сценарии), скрытое окно печати.

## Последствия

- Размер exe около 90–120 МБ.
- Нативный модуль SQLite пересобирается под версию Electron (`electron-rebuild` в CI) — или используется встроенный `node:sqlite`, если его версия в Electron достаточна.
- Безопасность Electron настраивается явно: `contextIsolation`, `sandbox`, CSP, запрет навигации.

## Рассмотренные варианты

- **Tauri** — маленький exe, но зависит от WebView2 на рабочем ПК и не даёт штатного PDF без окна печати.
- **Vue** (как в editor-of-tod) — легче, но без встроенного DI; для портов пришлось бы писать свой контейнер.
- **Локальный сервер + браузер** (как в editor-of-tod) — печать через окно браузера и лишний процесс.
