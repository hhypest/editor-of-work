# ADR-0004. PDF А3 через printToPDF в скрытом окне

**Статус:** принято · **Дата:** 20.10.2026

## Контекст

Листы ППР печатаются на А3 альбомно. В прототипе печать шла через окно браузера: пользователь мог выбрать не тот формат или поля. Нужно сохранять PDF сразу файлом, и он должен совпадать с предпросмотром.

## Решение

- Листы рисуются SVG и HTML по модели листа тем же Angular-кодом, что и предпросмотр.
- Main открывает скрытое окно в режиме `print`, передаёт модели листов, ждёт загрузки шрифтов и вызывает `webContents.printToPDF({ pageSize: 'A3', landscape: true, printBackground: true })` с нулевыми полями.
- Несколько листов в один файл склеиваются pdf-lib. Режимы: текущий лист, выбранные в один файл, выбранные отдельными файлами.
- Шрифты PT Sans и PT Sans Narrow (OFL) встроены в программу.

## Последствия

- PDF совпадает с экраном; формат задаётся кодом.
- Геометрия листа (подгон таблиц, выноски) считается в слое приложения через порт `TextMeasurer`, поэтому тестируется без браузера; итог проверяют эталонные снимки Playwright.

## Рассмотренные варианты

- **Генерация PDF библиотекой (pdfmake, PDFKit)** — второй движок отрисовки, расхождение с предпросмотром.
- **Окно печати браузера** — то, от чего уходим.
