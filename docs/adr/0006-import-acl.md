# ADR-0006. Импорт выгрузок через антикоррупционный слой

**Статус:** принято · **Дата:** 20.10.2026

## Контекст

Паспорт дистанции собирается из 17 форм ЕК АСУИ: «веб-страничные» xls (HTML с расширением xls), книги xlsx и отчёты BEx с многоуровневой шапкой и служебными листами. Номер файла меняется при каждой выгрузке. В данных есть особенности: после реорганизации прежние и новые подразделения одновременно открыты; в характеристиках по отрезкам столбец «ПД» содержит прежние коды; пустые значения записаны как «Нет данных», «-1», «-----»; в названиях переездов встречается не та станция; ликвидированная станция остаётся в выгрузках.

## Решение

- Модель ЕК АСУИ не проникает дальше контекста **Импорт**. Импорт пишет в паспорт только через сценарии паспорта, в черновик редакции.
- Конвейер: тип файла по содержимому → форма по набору заголовков → сырые строки → нормализация → перевод в понятия домена → сверки → набор изменений и замечаний → подтверждение пользователем → одна транзакция → отчёт в `import_file`.
- Строки отбираются по периоду действия на дату редакции. **Действующие подразделения отмечает пользователь** в мастере импорта.
- **ПД определяется по границам** отмеченных подразделений, а не по столбцу «ПД» характеристик.
- Импорт **ничего не исправляет молча**: расхождение — замечание, решение за пользователем. Исключения (ликвидированные станции) — список исключений редакции.

## Последствия

- Новая форма или изменённая шапка — новый распознаватель и парсер, домен не меняется.
- У каждой формы есть генератор вымышленной фикстуры с теми же особенностями (ADR-0008).

## Рассмотренные варианты

- **Читать выгрузки прямо в доменные объекты** — каждая смена формы ломала бы домен.
- **Доверять столбцу «ПД»** — даёт неверную принадлежность после реорганизации.
