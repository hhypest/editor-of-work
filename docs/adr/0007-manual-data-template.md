# ADR-0007. Нормативы и ручные данные — через шаблон xlsx, не в коде

**Статус:** принято · **Дата:** 20.10.2026

## Контекст

Части данных в выгрузках нет: нормативов (периодичность ремонтов, виды работ и единицы, допуски), пар поездов по участкам с разбивкой на грузовые, пассажирские и пригородные, длин нестандартных километров. Нормативы меняются редко, но меняются, и их источник должен быть виден.

## Решение

- Программа выдаёт **шаблон ручных данных** (xlsx) с листами «Виды работ», «Периодичность ремонтов», «Допуски», «Пары поездов», «Нестандартные километры», заполненными текущими значениями. Заполненный шаблон загружается тем же конвейером, что и выгрузки (ADR-0006).
- Те же данные можно править в программе; изменения попадают в черновик редакции.
- Норма периодичности задаётся по классу пути, конструкции и виду ремонта в **годах и млн т брутто**; ремонт нужен по первому достигнутому порогу.
- По каждому отрезку программа выводит **год последнего ремонта, просрочку и потребность в ремонте**. Год последнего ремонта главного пути — год последней укладки рельсов при любом признаке укладки; станционного — из экспликации. Эти значения вычисляются и не хранятся.
- Допуски — только справка, введённые значения по ним не проверяются.
- Числа нормативов не пишутся в код константами.

## Последствия

- Обновление нормативов не требует новой версии программы.
- Для первой редакции нормативы нужно один раз внести в шаблон.

## Рассмотренные варианты

- **Константы в коде** — каждое изменение норматива требовало бы релиза и скрывало бы источник числа.
- **Только формы в программе** — медленнее для первичного заполнения сотен строк.
