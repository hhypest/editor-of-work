# ADR-0009. Свой читатель xlsx на fflate вместо ExcelJS для импорта

**Статус:** принято · **Дата:** 21.10.2026

## Контекст

Архитектурный документ планировал ExcelJS и для чтения выгрузок, и для записи книг. При подключении выяснилось, что ExcelJS 4.4.0 через `unzipper` тянет пакеты с неясной лицензией. У `buffers` 0.1.1 лицензия не указана вовсе, у `chainsaw` 0.1.0 записано нестандартное `MIT/X11`. `check:licenses` по правилам проекта такие пакеты в exe не пропускает. HTML-разборщик для «веб-страничных» xls тоже оказался не нужен: выгрузки ЕК АСУИ — одна плоская машинная таблица.

## Решение

- **Чтение xlsx** — собственный модуль импорта (`libs/import/infrastructure/src/lib/export/xlsx-reader.ts`). Распаковку делает fflate (MIT, без зависимостей), XML разбирается регулярными выражениями. Модуль читает значения ячеек (у формул — сохранённый результат), даты по форматам стилей, объединения и видимость листов. Распаковываются только описание книги, общие строки, стили и видимые листы. Скрытые служебные листы BEx не распаковываются, а их в настоящих отчётах десятки.
- **Чтение «веб-страничных» xls** — разбор первой HTML-таблицы без сторонних библиотек.
- **ExcelJS** остаётся только в devDependencies: им генерируются книги вымышленных фикстур (#14).
- Писатель xlsx для административного деления (#32) и шаблона ручных данных (#19) выбирается в этих задачах по тем же правилам лицензий.

## Последствия

- В exe нет пакетов с неясной лицензией. Вся зависимость импорта от формата xlsx укладывается примерно в 200 строк, покрытых тестами на фикстурах и проверенных на настоящих выгрузках (вне репозитория).
- Поддерживать читатель нужно самим. Если ЕК АСУИ начнёт выгружать то, что он не понимает (например, двоичный xlsb), появится понятная ошибка «файл повреждён» с причиной.

## Рассмотренные варианты

- **ExcelJS с исключениями в `check:licenses`.** Это обходит собственное правило проекта для пакета без лицензии.
- **SheetJS.** Актуальная версия есть только на CDN разработчика, а версия в npm устарела и имеет известные уязвимости.
