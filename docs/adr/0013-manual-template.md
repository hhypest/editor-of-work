# ADR-0013. Версионированный шаблон ручных данных и запись в черновик

**Статус:** принято · **Дата:** 21.10.2026

## Контекст

ADR-0007 требует редактируемую книгу с текущими данными и без встроенных чисел
нормативов. ADR-0009 оставляет ExcelJS только в devDependencies из-за лицензий
его транзитивных пакетов. Для #19 нужны запись xlsx и защита от потери ручных
данных, если заполненную книгу вернут после изменения паспорта.

## Решение

Порт `ManualDataTemplate` объявлен в Import application. Адаптер main записывает
минимальный SpreadsheetML поверх уже подключённого fflate (MIT), читает книгу
существующим читателем xlsx. Формат следует [структуре SpreadsheetML Microsoft](https://learn.microsoft.com/office/open-xml/spreadsheet/structure-of-a-spreadsheetml-document).
Новых зависимостей нет. ExcelJS используется как независимый читатель/редактор
только в тестах. Открытие в настольном Excel 2007 остаётся ручной проверкой.

У книги пять видимых листов. Скрытый лист содержит идентификатор формата, версию,
дату редакции и токен основы. Скрытые столбцы идентификаторов сохраняют ключи при
редактировании и переименовании; новым строкам адаптер выдаёт ID. Периоды действия
видимы. Явные числовые значения обязательны: формулы отвергаются вместе с
сохранённым результатом, так как читатель не является вычислителем Excel.
Отсутствие листа или столбца — ошибка, а не команда очистить раздел.

`PassportManualData` публикует основу с текущими значениями, справочник направлений
с разрывами и классами пути, запись полного набора и журнал. Чистая проверка
опубликованного языка вызывается до предпросмотра и внутри транзакции. Проверяются
уникальность, ссылки и циклы видов работ, единицы вхождения, положительные пороги,
классы из паспорта, периоды, длины километров и границы/перекрытия пар поездов.
Допуски остаются справочными: с ними не сравниваются измеренные характеристики.

При записи повторно проверяется токен. Неизменённые данные, в том числе после
перестановки строк и сохранения Excel, не вызывают ни замены данных, ни изменения
журнала. Изменённый набор заменяет пять ручных разделов одной транзакцией.
Остальные данные паспорта не заменяются. Перед сокращением длины км проверяются
ранее принятые координаты: импорт не должен делать их недопустимыми.

Миграция 006 добавляет nullable `work_kind.symbol`. Прежние значения сохраняются,
существующие триггеры защищают новый столбец, копирование редакции переносит его.
Прежние миграции не меняются; существующий механизм делает backup до обновления.

## Последствия

Нормативы и их числа приходят из книги, первая книга не содержит примеров норм.
Перед загрузкой можно получить числа добавлений, изменений и удалений по листам.
После изменения основы нужно выдать новую книгу и перенести видимые изменения.
В старой книге нельзя подменять скрытые сведения, чтобы обойти проверку.

UI и диалоги выбора/сохранения файлов относятся к #21; расчёт срока ремонта и
просрочки по этим данным — к #20. Portable exe и релиз выпускает владелец вручную.
