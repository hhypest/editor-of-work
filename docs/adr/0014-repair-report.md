# ADR-0014. Потребность в ремонте — запрос согласованного среза редакции

**Статус:** принято · **Дата:** 21.10.2026

## Контекст

Расчёт #20 зависит от границ нескольких характеристик, норм из шаблона и даты редакции. Границы класса, рельсов и шпал не обязаны совпадать. Нормы с пустыми условиями могут пересекаться со специальными. История достижения тоннажа и тоннаж станционных путей в текущей модели импорта отсутствуют. При этом пользователю нужен отчёт в программе, а не только вычислительная функция.

## Решение

- Порт приложения читает весь исходный срез одной транзакцией SQLite. Чистый доменный сервис разбивает протяжение на однородные участки и оценивает каждый вид ремонта. Производные результаты не пишутся в БД; формат базы и файла плана не меняется.
- Более конкретная норма замещает общую только при включении всех её условий. Неизвестная характеристика не позволяет молча выбрать общую норму, если возможна специальная. Несопоставимые подходящие нормы дают явную неоднозначность.
- Ремонт требуется по первому достигнутому известному порогу. Недостаток данных отражается отдельно от отсутствия потребности. Неизвестные величины не заменяются нулём.
- Календарный год вычисляется по периоду нормы. Если есть тоннажный порог, общий год показывается как верхняя граница «не позднее»; точную дату достижения тоннажа и прогноз по неизменной годовой нагрузке программа не выдумывает.
- Отдельный IPC-канал принимает только идентификатор редакции и возвращает проверенный DTO. UI получает отчёт через порт и показывает результат, не импортируя домен или инфраструктуру. Начальный экран отчёта не заменяет мастер и редактор #21.

## Последствия

Расчёт воспроизводится для архивных редакций, проверяется без браузера и хранилища. Для точного исторического года достижения тоннажа понадобится отдельный источник истории. Частичная потребность по одному известному порогу уже доступна пользователю.

## Рассмотренные варианты

- Хранить просрочку в таблице — данные устаревают и противоречат ADR-0003 и ADR-0007.
- Выбирать норму по порядку строк или числу заполненных полей — несопоставимые условия дают случайный результат.
- Считать год тоннажа по текущей грузонапряжённости — неподтверждённое предположение о прошлых и будущих нагрузках.
