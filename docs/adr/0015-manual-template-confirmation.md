# ADR-0015. Подтверждение загрузки ручных данных через IPC

**Статус:** принято · **Дата:** 22.10.2026

## Контекст

Конвейер #19 уже выдаёт и проверяет книгу и атомарно заменяет ручные данные.
Интерфейс #21 должен показывать последствия до записи и не принимать пути к файлам
или подготовленные команды из renderer (ADR-0002, ADR-0006, ADR-0013).

## Решение

Раздел «Ручные данные» в Import feature-ui получает типизированный порт
`ManualTemplateClient` из Import application. Composition root связывает его с
preload. Контракт `import:manualTemplate` проверяет запрос и ответ zod в main.
Файлы выбираются только системными диалогами main; книга сохраняется через
уникальный временный файл рядом с целевым и переименование после синхронизации.

Подготовленная команда, включая данные книги и SHA-256, остаётся в main.
Renderer получает только имя файла, количества изменений по листам, ID редакции
и случайный одноразовый токен. Одновременно хранится один предпросмотр на процесс:
новая загрузка отменяет предыдущий. Токен привязан к редакции, действует 10 минут
и расходуется до попытки записи. Отмена не пишет данные и журнал.

Подготовка и подтверждение проверяют статус черновика; транзакция Паспорта
повторно проверяет неизменяемость и токен основы. Активация редакции или изменение
основы между предпросмотром и подтверждением приводят к отказу без перезаписи.
Параллельная операция с шаблоном отклоняется; интерфейс блокирует повторные действия
и смену редакции на время операции и до решения по предпросмотру.

## Последствия

Пути и содержимое книги не пересылаются renderer. После закрытия программы,
истечения срока или ошибки записи книгу нужно подготовить заново. Выдача доступна
для всех редакций; загрузка — только в черновик. Сам по себе предпросмотр не меняет
SQLite. Загрузка 17 форм ЕК АСУИ остаётся отдельным шагом #21.
Новых зависимостей и миграций нет.

## Рассмотренные варианты

- Передавать подготовленные данные обратно через renderer — лишний объём IPC и
  возможность подменить подтверждаемую команду.
- Сразу записывать выбранную книгу — пользователь не увидит удаления до замены.
- Перечитывать файл при подтверждении — содержимое может отличаться от предпросмотра.
