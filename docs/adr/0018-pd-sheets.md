# ADR-0018: Листы ПД по опубликованному срезу годового плана

**Статус:** Принято

**Дата:** 2026-10-22

## Контекст

Лист ПД должен повторять расчёты плана и сохранять прежний паспорт при открытии старого файла. Документы не могут обращаться к домену Планирования, даже транзитивно. Выноски и таблицы должны помещаться на А3 без изменения данных.

## Решение

`planning/sheet-api` публикует DTO `PlanSheetData`, зависящий только от ядра. Проекция `planSheetData` в `planning/application` использует существующие `shareIn`, `workVolume` и `planRows`: доли, «входит в», ручные значения и потребность не реализуются повторно в Документах. UI и геометрия импортируют только опубликованный DTO. Ограничения Nx не изменяются.

Действие `previewSheets` существующего канала `plan:file` возвращает отдельный вариант `sheets` с проверкой zod. Main последовательно читает текущий план либо выбранный файл. Чтение файла для просмотра не вызывает замену состояния и не меняет путь сохранения или автокопию. Формат файла не меняется. До проекции проверяется бюджет сложности, до IPC — размер ответа 20 МиБ.

`documents/application` разбивает границы ПД на ряды через `KmLengths`, упаковывает прямоугольники выносок в четыре полосы и повторяет ряд для остатка. Подписи соседей используют точное равенство координат смежных границ. Табличные строки измеряются до пагинации, заголовок повторяется на каждой странице; шрифт не ужимается ниже 2,5 мм. Превышение пределов возвращает `Result` с объяснением.

Первый snapshot листа ПД фиксирует вымышленные данные: два раздельных ряда, нестандартный км, соседние ПД, выноску, гриф и таблицу показателей. Эталон общей схемы #22 не меняется. Сам SVG-компонент переиспользуется с общей подписью доступности «Лист А3».

## Последствия

Листы можно просматривать до реализации редактора #24. Работы станции остаются в ведомости: текущий срез плана не хранит координаты её осей. Этот шаг показывает вычисляемые показатели длины и числа работ; остальные показатели и их ввод подключаются в #24. PDF и сравнение с прототипом остаются в #25–#26.

## Рассмотренные варианты

- Читать новый паспорт из SQLite при каждом открытии: изменит смысл старого плана.
- Дать Документам доступ к домену Планирования: нарушит границы контекстов.
- Ужимать любые таблицы на один лист: приведёт к нечитаемому тексту; приняты измерение и продолжения.
