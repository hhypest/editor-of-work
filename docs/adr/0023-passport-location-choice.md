# ADR-0023: Явный выбор при обнаружении двух баз паспорта

**Статус:** Принято

**Дата:** 2026-10-22

## Контекст

После временной недоступности папки программы паспорт мог измениться в локальной базе. При возвращении переносной базы прежний приоритет рядом с exe скрывал эти изменения. Аудит 1.4 требует обнаружения двух баз и явного выбора.

## Решение

До открытия SQLite проверяем оба штатных пути. Если существуют два разных файла, main показывает системное предупреждение с полными путями и выбором: закрыть программу, открыть базу рядом с программой или базу на этом компьютере. Закрытие и Escape отменяют запуск; по умолчанию выбрано закрытие. Без обработчика выбора открытие двух баз отклоняется.

Выбор относится только к текущему запуску. Выбранная база открывается по прежним правилам совместимости и резервного копирования; ошибка не запускает другую базу. Невыбранная база не открывается, не мигрирует и не копируется. Автоматического объединения, удаления или замены нет. Два пути к одному физическому файлу не требуют выбора.

При единственной базе сохраняются прежние правила: существующая локальная база продолжается, если переносной нет; резервный путь используется при недоступности записи. Выбор хранится только в main и не передаётся через IPC.

## Проверка

Вымышленные временные базы с различающимися редакциями: переносная → недоступность → локальная → возвращение переносной. Проверяются оба выбора и отмена, неизменность невыбранного файла, отказ выбранной повреждённой базы без переключения и повторный выбор при следующем запуске. Отдельно проверяются соответствия кнопок системного диалога и отмена до открытия базы.

## Последствия

Составитель видит оба места хранения и принимает решение перед работой с паспортом. Выбор не определяет, какая база новее, и не решает перенос или восстановление из #38. Приёмка системного окна в настоящем Electron Windows проверяется отдельно от модульных тестов.

## Рассмотренные варианты

Приоритет переносной базы сохранял скрытое расхождение. Выбор по времени файла ненадёжен при копировании и WAL. Автоматическое объединение редакций требует отдельного сценария переноса и не допускается этим изменением.
