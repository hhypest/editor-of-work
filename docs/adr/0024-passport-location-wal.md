# ADR-0024: Выбор пути базы с учётом WAL

**Статус:** Принято

**Дата:** 2026-10-22

## Контекст

Ревью #76 выявило риск в исключении ADR-0023 для двух ссылок на общий файл. После аварийного завершения закоммиченные изменения могут оставаться в `passport.sqlite-wal` только рядом с одним из путей. Совпадение устройства и inode основного файла не доказывает тождество состояния SQLite.

## Решение

Заменяем ADR-0023, сохраняя явный выбор до открытия SQLite: при наличии обоих штатных путей main показывает полные пути и требует выбрать переносную или локальную базу либо закрыть программу. Отмена выбрана по умолчанию, Escape и закрытие окна отменяют запуск. Без обработчика выбора открытие отклоняется. Выбор относится только к текущему запуску и повторяется при следующем.

Исключения по inode и каноническому имени нет: журналы WAL/SHM относятся к открываемому пути. Выбранный путь открывается с прежними проверками схемы и копией до миграции. Ошибка не переключает путь; другой путь не открывается и не мигрирует. Для разных физических файлов невыбранная база сохраняется побайтно. При жёстких ссылках основной файл общий, поэтому изменение через любой путь затрагивает общий файл; такая раскладка не является двумя независимыми копиями и не рекомендуется.

Когда существует только один штатный путь, действуют прежние правила выбора и резервного размещения. Копирования поверх другой базы, автоматического объединения, удаления или запоминания выбора нет. Перенос и восстановление остаются в #38.

## Проверка

Сценарии ADR-0023 сохраняются, кроме обхода выбора для общего файла. Вместо него тест создаёт жёсткую ссылку на базу, отдельным процессом коммитит редакцию в локальный WAL и завершает процесс без закрытия SQLite. После явного выбора локального пути читаются обе редакции, включая запись из WAL. Отмена до открытия проверяется также при наличии двух путей к общему файлу.

## Последствия

Программа не считает две базы одинаковыми по метаданным основного файла и не скрывает выбор пути после аварии. Выбор не определяет, где данные полнее: перед ручным переносом сохраняют базу вместе с её журналами. Приёмка окна в настоящем Electron Windows остаётся отдельной проверкой.

## Рассмотренные варианты

Проверка только inode отвергнута из-за отдельных журналов. Сравнение времени файлов, хеширование основного файла и сравнение содержимого без согласованного состояния SQLite также не подтверждают тождество. Для этого исправления безопаснее требовать явный выбор пути.
