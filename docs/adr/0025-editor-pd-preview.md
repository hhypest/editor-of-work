# ADR-0025: Предпросмотр ПД по ревизии редактора

**Статус:** Принято

**Дата:** 2026-10-23

## Контекст

Редактор #24 и листы ПД #23 используют один план в main, но доступны на разных
экранах. Требуется видеть применённую правку без сохранения и повторного открытия
файла. Документы не могут импортировать домен Планирования; Планирование не
должно зависеть от Документов.

## Решение

Composition root UI соединяет редактор и отдельный компонент предпросмотра через
контекст `PlanPreviewContext` из опубликованного `planning/sheet-api`. В нём только
ревизия, область и признаки состояния; полной копии плана в renderer нет.
Редактор публикует контекст через output и слот проекции, не импортируя Документы.

Чтение `previewEditorSheets` передаёт ожидаемую ревизию и идентификатор ПД.
Main в общей очереди проверяет ревизию и возвращает опубликованный срез с той же
ревизией. Работы и таблицы рассчитываются только выбранному ПД, границы остальных
сохраняются для подписей соседей. Прежнее чтение всех ПД остаётся совместимым.
Срез ограничен прежними бюджетами сложности и размера IPC. Ошибка предпросмотра
не отклоняет уже применённую правку и не меняет историю, путь или файл.

При операции редактора, смене ревизии/ПД и ошибке прежний лист скрывается.
Поколение асинхронного запроса защищает также ожидание шрифтов. Незавершённый ввод
не отправляется в срез: интерфейс явно отмечает, что лист показывает применённые
изменения. Zoom независим от масштаба схемы. В пределах того же ПД индекс страницы
сохраняется и ограничивается новым числом страниц; смена ПД начинает с первой.

## Последствия

Используются прежние `buildPdSheets` и SVG-компонент. Формат файла, SQLite,
предметный расчёт долей и геометрия листов не меняются. Фильтр относится ко всему
ПД, включая продолжения. Фильтр физической страницы, дополнительные таблицы,
PDF и замер полного отклика renderer менее 200 мс остаются в #24–#26.

## Рассмотренные варианты

- Импорт Документов из planning/feature-ui нарушает направление зависимостей.
- Чтение без ревизии может показать новый план рядом с прежним редактором.
- Полная проекция всех ПД после каждой правки повторяет ненужные расчёты.
