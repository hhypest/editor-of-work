# ADR-0027: Фильтр списка работ по готовой странице ПД

**Статус:** Принято

**Дата:** 2026-10-23

## Контекст

ADR-0025 связывает предпросмотр с ревизией редактора, но список работ ограничен
только ПД. Физическая страница может содержать часть направления, продолжение
выносок, строки ведомости либо только сводные таблицы. Проверка координат в UI
не воспроизведёт пагинацию и потеряет станционные работы.

## Решение

Планирование публикует необязательные `workIds` у таблицы: один ID на строку
ведомости. Существующие строки и геометрия не меняются. Документы проверяют
соответствие числу строк и ссылкам на работы ПД. В `PdDocument.workIdsByPage`
геометрия собирает уникальные ID видимых отметок и размещённых строк ведомости.
Работа без выноски входит по отметке, станционная — по ведомости. Повторённый
схематический ряд содержит те же отметки и те же работы. Сводная таблица сама
по себе не добавляет работы. Принадлежность не определяется по тексту заголовка.

Компонент листов публикует `PlanPageSelection`: ревизия, область, номер страницы
и ID. При загрузке, ошибке, найденной автокопии или отсутствии листа публикуется
`null`. Composition root передаёт DTO в редактор; контексты не импортируют друг
друга. Редактор принимает только выбор своей ревизии и области.

Режим «Весь ПД / Текущий лист» меняет только отображаемый список. Пустая страница
не подменяется всем ПД. Итоги таблиц остаются по области. Переключение страниц,
масштаба и режима не является командой плана, не создаёт историю и не сбрасывает
черновик работы, даже если редактируемая работа перестала попадать в список.
Для дистанции и станции сохраняется прежний список области.

## Последствия

Формат v3 и SQLite прежние; метаданные вычисляются при подготовке листов.
Эталонные snapshots получают только `workIdsByPage`; примитивы прежних листов
не меняются. Предметные тесты проверяют границы рядов и нестандартный километр,
продолжения ведомости, станционные работы, выключенную выноску, пустые страницы,
устаревшие ответы и сохранность черновика. Замер renderer <200 мс и PDF остаются
отдельными шагами.

## Рассмотренные варианты

- Фильтровать координаты в Angular: дублирует геометрию и не учитывает ведомость.
- Считать любую страницу всеми работами ПД: не выполняет фильтр физического листа.
- Распознавать ID по заголовкам и тексту SVG: ломается при одинаковых названиях.
