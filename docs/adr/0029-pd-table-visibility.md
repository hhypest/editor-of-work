# ADR-0029: Состав таблиц ПД и формат v5

**Статус:** Принято

**Дата:** 2026-10-23

## Контекст

После ADR-0028 масштаб ПД сохраняется в плане. Следующий параметр #24 — набор
таблиц на листах. В программе есть шесть семейств: текущий план, капитальные и
прочие работы, сводные показатели, ведомость и ручные показатели. Точной структуры
оформления HTML-прототипа нет; неизвестные поля его архива не преобразуются.

## Решение

План хранит скрытые семейства отдельно по ID ПД. Стабильные ключи не зависят от
русских заголовков. Пустой набор означает прежний вывод всех доступных таблиц;
пустые группы работ по-прежнему не рисуются. Домен проверяет ПД, ключи и отсутствие
повторов, нормализует порядок, владеет копией массива. Одинаковый набор не создаёт
новую версию плана. Возврат всех таблиц удаляет переопределение.

UI показывает шесть флажков и черновик. Применение пакета — один шаг истории;
ошибка сохраняет ввод. Ctrl+S применяет его перед записью, переходы и закрытие
используют общую защиту незавершённых форм. Настройка относится ко всему ПД.

Планирование отбирает таблицы при подготовке среза. Работы, показатели, ручной
план и потребность не удаляются, редактор продолжает показывать полные данные.
Документы используют прежнюю геометрию; новая пагинация обновляет фильтр текущей
страницы. Скрытая ведомость не выводит станционные работы. UI объясняет это у
флажка, замечания листов сообщают об отсутствии ведомости вместо утверждения,
что работы в ней показаны. Связь со строками определяется по workIds, не по тексту
заголовка.

Формат v5 добавляет `plan.pdHiddenTables`: ID ПД и ключи скрытых семейств. Миграция
v4 → v5 добавляет пустой список; схемы и вымышленные образцы v1–v4 сохраняются.
Срез, checksum, работы, показатели, ручные значения, масштабы и строка архива
прототипа не изменяются. FilePlanStore по-прежнему создаёт .bak и автокопии,
будущую версию не перезаписывает. SQLite не меняется.

## Последствия

Новых зависимостей нет. Тесты проверяют изоляцию ПД, владение данными, историю,
все прежние форматы, резервную копию/восстановление, черновик и UI → SVG, скрытую
ведомость и фильтр страницы. Для настроек по умолчанию примитивы прежние;
отдельный эталон закрепляет лист с отключёнными таблицами. Оформление таблиц,
ожидаемые показатели, подрядные/ИССО/ЗП и PDF остаются следующими шагами.

## Рассмотренные варианты

- Удалять данные таблиц: нарушает смысл настройки вывода.
- Отбирать по русским заголовкам: связывает поведение с редактированием текста.
- Хранить локально в просмотре: файл не воспроизводится на другом компьютере.
