# ADR-0033: Перенос ожидаемых показателей из проекта HTML-прототипа

**Статус:** Принято

**Дата:** 2026-10-27

## Контекст

ADR-0026 оставил дополнительные таблицы прототипа в архиве плана: без их точной
структуры перенос мог исказить данные. Для ожидаемых показателей структура известна
из исходного кода прототипа: `tables[область].expected` — массив строк
`{ group, name, unit, value }`, где область — `dist` или идентификатор ПД, `group` —
показатель, `name` — составляющая «в т.ч.», `value` — число или пусто. Эта же модель
реализована в плане (ADR-0031).

## Решение

Импорт прототипа переносит `tables.dist.expected` в ожидаемые показатели дистанции,
а `tables.<ПД>.expected` — в показатели этого ПД, сохраняя порядок строк. Новые ID
выдаёт IdGenerator импорта. Текст обрезается по краям; число допускается числом или
строкой с запятой либо точкой и знаком; `null`, отсутствие и пустая строка — значение
«не задано», ноль сохраняется нулём.

Ничего не исправляется молча. Строка без показателя, нечисловое значение, поле
показателя, «в т.ч.» или единицы, которое не является текстом или числом (объект,
массив, логическое значение), нераспознанная строка и таблица станции не переносятся и называются в отчёте
импорта; лишние поля строки тоже названы. Исходный JSON по-прежнему хранится в
архиве плана побайтно, поэтому пропущенное можно восстановить вручную. Более
10 000 строк в области отклоняют импорт целиком, как и другие ошибки.

Перенесённая таблица больше не числится в отчёте как неперенесённая. Остальные
таблицы прототипа (показатели, подрядные работы, ИССО, ЗП) остаются в архиве до
своих шагов #24.

## Последствия

Формат плана, SQLite и зависимости не меняются: строки записываются в существующий
v6 через доменную проверку. Тесты проверяют перенос дистанции и ПД, пустое значение,
ноль, знак и запятую, отчёт о каждой пропущенной строке и о таблице станции, предел
строк, а в main — импорт, сохранение и повторное открытие.

## Рассмотренные варианты

- Подставлять показатель предыдущей строки в строку без показателя: угадывание,
  которое меняет смысл таблицы.
- Отклонять весь импорт из-за одной неполной строки: блокирует перенос проекта
  ради поправимой мелочи, которая видна в отчёте.
