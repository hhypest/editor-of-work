# ADR-0042: Переносная сборка и ручной выпуск

**Статус:** Принято

**Дата:** 2026-10-27

Реализует поставку из [ADR-0002](0002-angular-electron.md) (#6). Хранилище — встроенный `node:sqlite` по [ADR-0021](0021-node-sqlite-runtime.md).

## Контекст

Рабочие ПК — Windows 10/11 x64 без прав администратора и без интернета. Нужен один exe без установки, база паспорта в папке `data` рядом с ним и контрольная сумма для проверки после переноса. AGENTS.md запрещает автоматическую публикацию: сборка exe и выпуск запускаются только вручную владельцем. Программа не обращается к сети.

## Решение

- electron-builder, цель `portable` x64, `requestExecutionLevel: user`. Конфигурация — объект в `scripts/package-portable.mjs`, команда — `npm run package:portable`.
- В программу попадают только собранные main и preload (`dist/apps/desktop`, без карт исходников), интерфейс в `resources/ui`, лицензии в `resources/licenses`. `node_modules` не упаковываются: main и preload собраны esbuild, интерфейс — Angular. Заставка `default_app.asar` удаляется.
- Electron берётся из `node_modules/electron/dist` (`electronDist`), то есть той же версии из lock-файла, что прошла `check:electron` и сквозной сценарий; при сборке Electron не скачивается.
- `publish: null`: из сборки ничего не публикуется и автообновления нет.
- Сборка идёт с `NODE_ENV=production` и без кэша Nx. `NODE_ENV` и корневой `package.json` — входы кэша `desktop:build`, чтобы обычная сборка не подхватила вывод другой конфигурации или версии.
- Рядом с exe пишется `<exe>.sha256` в формате `sha256sum`.
- Workflow `Portable exe` запускается только кнопкой (`workflow_dispatch`) на windows-latest: полный `check`, `check:electron`, сборка, сквозной сценарий в упакованной программе (`EOW_E2E_EXECUTABLE`, папка с пробелом и кириллицей), запуск самого exe с проверкой `data/passport.sqlite` рядом с ним и нетронутого профиля. Exe, SHA-256 и отчёты — артефакт. Черновик Release создаётся, только если владелец отметил `draft_release`; опубликовать его может только он.

## Последствия

- Программа без иконки и подписи: Windows SmartScreen может предупредить при первом запуске. Иконка и подпись — отдельные решения.
- Portable-обёртка при каждом запуске распаковывает программу во временную папку; первый запуск медленнее. База и PDF пишутся не туда, а в `data` рядом с exe.
- Проверка exe на чистой Windows 10/11 без прав администратора остаётся пунктами 1–2 приёмки на рабочем ПК.
