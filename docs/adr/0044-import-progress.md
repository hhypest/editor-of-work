# ADR-0044: Ход и остановка подготовки импорта выгрузок

**Статус:** Принято

**Дата:** 2026-10-28

Продолжает мастер импорта ([ADR-0010](0010-passport-import-api.md)) и следует идее пакетного PDF ([ADR-0039](0039-pd-batch-pdf.md)): долгую операцию видно и можно остановить.

## Контекст

Шаг мастера — одна команда `choose` канала `import:exports`: системный диалог, чтение файлов с диска, разбор форм и сверка с паспортом выполняются в main, renderer ждёт ответа. На вымышленном комплекте это меньше секунды, на реальных выгрузках дистанции — заметно дольше, а интерфейс показывал только «Чтение и проверка выгрузок…» без возможности прервать неудачный выбор файлов. В пакетном PDF шаги ведёт renderer, поэтому ход у него есть сам собой; при импорте файлы читает только main, а путь к ним renderer не знает (ADR-0006). IPC программы — только запрос-ответ, без рассылки событий из main.

## Решение

- Канал `import:exports` получает действия `progress` и `cancel`. Main отвечает на них и во время текущей операции, не считая их новой операцией: `idle`, если ничего не выполняется, иначе `progress` с этапом (`reading`, `parsing`, `checking`, `saving`), номером файла, их числом, именем файла и признаками «можно остановить» и «останавливается».
- Чтение и разбор вызывают шаг `ExportStep` перед каждым файлом и после последнего. Шаг в main записывает ход, отдаёт очередь событий (`setImmediate`), чтобы ответить на запросы хода, и при запрошенной остановке прерывает операцию. Отмена проверяется между файлами и после сверки с паспортом: файл разбирается целиком, остановка во время сверки отбрасывает её результат.
- Остановленная подготовка возвращает `cancelled`, сеанс подтверждения не создаётся, база не меняется. Запись (`apply`) — одна транзакция SQLite; во время неё ход `saving`, остановка недоступна.
- Renderer опрашивает ход раз в 400 мс только пока идёт `choose` или `apply`, показывает этап и файл и кнопку «Остановить». После остановки — сообщение, что ничего не записано.

## Последствия

- Видно, на каком файле идёт работа; неудачный выбор прерывается без ожидания.
- Остановка срабатывает после текущего файла: один очень большой файл по-прежнему читается до конца.
- Шаблон ручных данных и импорт проекта прототипа работают с одним файлом и не получают хода; при долгой загрузке на реальных данных — отдельное решение.
