# ADR-0047: Правка раскладки станции в редакторе

**Статус:** Принято

**Дата:** 2026-11-02

Продолжает [ADR-0046](0046-station-scheme-pdf.md) (раскладка из PDF схемы) и задачи #29–#30: схему станции правят мышью с привязкой к сетке, одно перетаскивание — один шаг отмены, стрелка всегда лежит на своём пути.

## Контекст

После импорта схемы раскладка уже верна по топологии, но составителю нужно поправить вид: развести подписи, выровнять пути, исправить номер, который схема подписала неоднозначно. Раскладка хранится в паспорте (`station_layout`), контекст станций по правилам Nx не видит домен паспорта, а renderer не обращается к базе.

## Решение

- **Модель и правила** — `libs/stations/domain`: узел переносится только в свободную клетку сетки; стрелка — только вдоль своего ряда, чтобы путь прямого направления не изгибался; узлы каждого пути остаются слева направо; остряки и мосты не выходят за свой путь. Правка, нарушающая правило, отклоняется целиком с текстом причины. Номер пути уникален в станции; съезд номера не получает; станционный путь без номера становится путём без номера и обратно.
- **Сеанс правки** — `libs/stations/application`: история отмены из общего ядра; все сдвиги одного перетаскивания идут с одним ключом и отменяются одним шагом, каждое нажатие стрелки клавиатуры — отдельный шаг. Там же модель рисунка: точки путей, подписи, остряки и мосты на линиях своих путей.
- **Хранение** — порт `PassportStationLayouts` в `passport/import-api`: список станций редакции, раскладка с версией (SHA-256 сохранённого JSON) и признаком «можно править», запись. Записывается только черновик и только при совпадении версии: правку, сделанную после открытия, программа не затирает. Ссылка на файл схемы, из которого пришла раскладка, сохраняется. Main проверяет раскладку той же схемой zod и правилами формата, что и импорт.
- **Интерфейс** — раздел «Схемы станций»: выбор редакции и станции, SVG по модели рисунка, перетаскивание на pointer-событиях, стрелки клавиатуры, Ctrl+Z / Ctrl+Y / Ctrl+S, таблицы путей и стрелок с правкой номеров. Действующая и архивная редакции открываются только для просмотра.

## Последствия

- Схему импортированной станции можно довести до вида листа без повторного импорта; повторный импорт PDF заменяет раскладку целиком (ADR-0046).
- Узел пути с изломом можно сдвигать свободно, поэтому наклон ответвления после правки может отличаться от стандартного.
- Объекты схемы (здания, новые переезды), привязка работ к путям и листы станций — следующие задачи (#30, #31).

## Рассмотренные варианты

- **Хранить только ручные сдвиги поверх импортированной раскладки.** Повторный импорт смешал бы старые сдвиги с новой топологией; проще и честнее править саму раскладку и заменять её при импорте.
- **Свободное перемещение стрелки.** Путь прямого направления изгибался бы, и стрелка визуально уходила бы с пути.
- **Писать раскладку без проверки версии.** Две открытые правки молча затирали бы друг друга.
