# ADR-0053: Схема дистанции, вариант C — схема-таблица

**Статус:** Принято

**Дата:** 2026-11-02

Задача #35: схема дистанции таблицей — станции по направлениям, под ними участки ПД и ПЧУ, PDF А3.

## Контекст

Вид листа согласован по образцу, который прислал пользователь (служебный файл, в репозиторий не добавлен). Данные те же, что у варианта A (ADR-0050): срез общей схемы с ПЧУ, руководителями, названием дистанции, путями и стрелками станций и списком станций без привязки к ПД.

## Решение

- **Шапка** общая с вариантом A (`districtHeader`), подзаголовок «Схема-таблица: …».
- **Столбцы** — станции каждого направления в порядке осей; направления — в порядке паспорта. Станция примыкания на втором направлении повторяется, её показатели заменены «*» и учитываются один раз. Станции без привязки к ПД не показываются и перечислены в примечании.
- **Принадлежность станции к ПД** — по положению оси между границами участка ПД этого направления. Участок ПД без станций на направлении получает пустой столбец, чтобы его длина и границы были видны. Станция вне участков ПД получает столбец с «—» и замечание; в итоги она не входит.
- **Строки таблицы:** направление, станция (вертикально), ось (км+м, вертикально), главный путь с осями, число станционных путей, их длина, стрелочные переводы, линейный участок с руководителем, длина главного пути ПД, границы ПД (красным), эксплуатационный участок (тёмная заливка, белый текст). Части одного ПД подряд — один участок с несколькими диапазонами («181+000 — 213+400; 218+600 — 280+000»), длина — сумма частей по длинам километров направления. Подряд идущие ПД одного ПЧУ — одна ячейка в пределах направления.
- **Ширина столбцов** — поровну в ширину листа, от 9 до 16 мм. Если станций больше, чем помещается, таблица делится по направлениям (длинное направление — по столбцам) на несколько таблиц и листов.
- **Итоги по ПЧУ:** руководитель, ПД с руководителями, главный путь, станционные пути, стрелки, число станций; ПД без ПЧУ — строка «Без ПЧУ»; «ВСЕГО» — число ПЧУ и ПД. Справа — примечания: правило станционных путей, станции примыкания, части направлений вне дистанции, станции без привязки к ПД.

## Последствия

- Вариант C не зависит от годового плана и строится по любой редакции паспорта.
- Итоги варианта C и административного деления (ADR-0052) считаются по одним правилам путей и стрелок; станции к ПД в административном делении относятся по привязке станций, а в варианте C — по положению оси. Если они расходятся, это видно по итогам; замечание о станциях вне участков указывает на причину.

## Рассмотренные варианты

- **Привязка станций к ПД из оргструктуры.** В срезе схемы её нет, а положение оси однозначно задаёт столбец в нужном участке таблицы.
- **Уменьшение шрифта вместо деления таблицы.** При сотне станций подписи стали бы нечитаемы.
