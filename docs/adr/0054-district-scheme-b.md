# ADR-0054: Схема дистанции, вариант B — топологическая

**Статус:** Принято

**Дата:** 2026-11-02

Задача #34: топологическая схема дистанции — направления без масштаба, связи направлений, участки ПД и ПЧУ, PDF А3.

## Контекст

Вид листа согласован по образцу, который прислал пользователь (служебный файл, в репозиторий не добавлен). В образце расположение направлений нарисовано вручную. Программа работает с любой дистанцией, поэтому расположение строится по данным: общие станции направлений и общие концы направлений, названные в их именах.

## Решение

- **Данные** — те же, что у вариантов A и C (`districtLines`): станции по осям, участки ПД (части одного ПД подряд — один участок), разрывы протяжения, руководители, пути и стрелки станций.
- **Ряд направления** — внемасштабная линия: точки (концы частей, границы ПД, станции) в порядке координат; расстояния пропорциональны длине по главному пути с общим коэффициентом, но станции не ближе 8 мм, остальные точки — 3 мм. Разрыв протяжения — серый пунктир постоянной длины.
- **Цвет линии — ПЧУ** (шесть различимых цветов, ПД без ПЧУ — серый). Станция — белый кружок с обводкой цвета ПЧУ и названием наискось (поворот −45°; примитив текста получил этот поворот, кружок — заливку, обводку и толщину). Граница ПД — чёрная засечка с координатой; под линией — «ПД · руководитель».
- **Связи.** Станция, общая для двух направлений, — станция примыкания: рисуется один раз крупным чёрным кружком, второе направление сдвигается так, чтобы его ось этой станции оказалась на той же вертикали, и соединяется с ней линией цвета своего ПЧУ. Из двух ориентаций второго направления выбирается та, при которой схема уже. Общий конец направлений, не являющийся станцией дистанции (по названиям «А — Б»), — узел «вне границ дистанции» с пунктиром к концам, если концы оказались на одной стороне.
- **Концы направлений** подписаны «на Вязьму», «на Духовскую» — винительный падеж по окончанию (-ая → -ую, -а → -у, -я → -ю), прочие названия без изменений.
- **Ряды** идут в порядке обхода связей от самого связанного направления; если по ширине не помещаются, схема сжимается; по высоте — ряды переходят на следующий лист, связи между листами не рисуются.
- **Итоги по ПЧУ** — цветная черта, «ПЧУ · руководитель — км» и строки ПД (главный путь, станции, станционные пути, стрелки); в подвале — условные обозначения, итоги дистанции и станции без привязки к ПД.

## Последствия

- Схема строится по любой редакции без ручной расстановки; вид может отличаться от нарисованного вручную образца, но связи и участки те же.
- Склонение подписей «на …» простое: для редких названий форма может быть неточной; это подпись, а не данные.

## Рассмотренные варианты

- **Ручная расстановка направлений пользователем.** Требует нового редактора и хранения раскладки в паспорте; отложено, пока автоматическая расстановка не окажется недостаточной на рабочих данных.
- **Масштабная линия.** Это вариант A; в топологической схеме важнее порядок станций и связи.
