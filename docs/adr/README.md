# Архитектурные решения (ADR)

Каждое значимое решение записывается отдельным файлом `NNNN-короткое-имя.md`. Принятый ADR не переписывают: если решение меняется, пишут новый ADR со ссылкой на прежний и меняют статус прежнего на «Заменён ADR-NNNN». Реализованный выбор SQLite уточнён в [ADR-0021](0021-node-sqlite-runtime.md).

Формат: **Статус**, **Дата**, **Контекст**, **Решение**, **Последствия**, **Рассмотренные варианты**.

Редактор годового плана: [ADR-0019 — история и типизированные команды](0019-plan-editor.md).
