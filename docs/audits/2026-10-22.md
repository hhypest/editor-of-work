## Ограничение чтения и совместимость

Лимит дискового чтения — **80 МиБ байтов** на файл. Лимит IPC остаётся **20 МиБ единиц строки JavaScript (UTF-16)**. Разные единицы выбраны явно: перевод прежнего ограничения в 20 МиБ UTF-8 отвергал бы допустимые русские примечания. 80 МиБ с запасом покрывают любую строку, проходящую прежний IPC; формат v1/v2 не меняется.

Большой файл отклоняется до чтения содержимого. Рост после stat выявляется по фактическому числу байтов; читается не более лимита плюс один контрольный байт. Для ошибочного файла не меняются текущий документ, путь и история. Отказ при чтении старой резервной копии также прерывает сохранение вместо её молчаливой потери.

## Очередь разработки

1. Завершить создание плана из паспорта (#24, отдельный PR #73) и эти исправления чтения/URI. Оба PR направлены в main и не сливаются автоматически.
2. Ограничить **распаковку** OOXML и проверить неверные размеры ZIP, CDATA/атрибуты shared strings. Сохранить обратную совместимость распознавания форм и понятные ошибки; не подменять парсер стилевым рефакторингом.
3. Сделать индикацию двух баз и явный выбор без копирования поверх другой базы. Добавить тест «primary → fallback → возвращение primary»; включить в приёмку #38.
4. В #6 проверить запуск настоящего Electron на Windows: process.versions, node:sqlite, backup и открытие временной базы, затем portable. До этого совместимость production-рантайма не считается подтверждённой.
5. Вернуться к дополнительным таблицам, настройкам и связи с текущим листом #24, затем PDF #25 и приёмке #26. Предрелизная очередь учитывает проверки 2–4, а не только закрытие функциональных задач.
6. Отдельно: lazy-маршруты, oxlint-предупреждения, матрица Node/engines и диагностика dev URL. Пороги, предупреждения и Nx-границы не ослаблять.

## Проверка этого шага

Предметные тесты охватывают заявленный размер до чтения, рост файла, границу лимита, многобайтовый UTF-8, закрытие файла, отказ большого плана/прототипа/автокопии без смены пути и некорректные URI. Полный npm run check и CI проверяются в PR. Ручной запуск Electron и приёмка Windows остаются в #6/#26; этот документ не закрывает их.
