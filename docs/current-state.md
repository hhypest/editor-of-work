# Текущее состояние

Состояние `main` на 27.10.2026 с учётом PR #92–#102. Документ описывает только то, что уже есть в программе; целевое устройство — в [архитектуре](architecture.md), очередь работ — в [дорожной карте](roadmap.md), условия выпуска — в [критериях 0.5.0](releases/0.5.0.md). Обновляется в том же PR, который меняет возможности программы.

## Матрица возможностей

«Есть» — сценарий работает в программе через интерфейс и покрыт автотестами домена, сценариев, IPC и UI. «Частично» — работает часть критериев задачи. «Проверено на ПК» — ручной прогон через настоящий интерфейс Windows на вымышленных данных; проверка на реальных выгрузках составителя — часть приёмки выпуска.

## Известные ограничения

- Готового exe нет; программа запускается из исходников (`npm start`) или локальной сборкой.
- Рабочим инструментом до конца этапа 4 остаётся HTML-прототип «Редактор схем ППР».
- Ручная проверка 23.10.2026 описана в [протоколе](testing/windows-ui-2026-10-23.md); она охватывает редактор и PDF на вымышленном плане v5, но не импорт и не portable.
