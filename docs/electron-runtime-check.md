# Проверка SQLite в Electron

`npm run check:electron` проверяет требование ADR-0021 на настоящем Electron из
lock-файла. Перед запуском выполните `npm ci` и `npm run build`: проверка использует
миграции из собранного desktop. На Windows команда запускается непосредственно;
на Linux нужен графический сеанс либо `xvfb-run -a npm run check:electron`.

В отдельной временной папке создаётся вымышленный паспорт. Проверяются создание
схемы, WAL, работа публичного адаптера через Kysely, активация двух редакций,
резервная копия состояния до каждой активации и повторное открытие основной базы.
Проба отказывается работать под обычным Node и не использует
`ELECTRON_RUN_AS_NODE` или флаги включения SQLite. Тестовых ветвей в production
main нет; код пробы собирается отдельно и не входит в поставку.

Процесс ограничен тайм-аутом. Ненулевой код, сигнал, отсутствие корректного отчёта
или несовпадение версии Electron с установленным пакетом означают отказ. После
успеха отчёт с версиями Electron, встроенного Node и SQLite и именами проверок
находится в `test-results/electron-runtime/report.json`. В CI Windows он сохраняется
как артефакт; базы, журналы и данные паспорта не загружаются. Временная папка
удаляется и при ошибке; прежний отчёт удаляется перед новым запуском.

Проверка доказывает совместимость хранилища со встроенным Node Electron. Она не
проверяет production main/preload, интерфейс Angular, PDF или переносной exe.
Эти проверки, ручная сборка и приёмка на рабочем ПК остаются в #6/#26/#27.
