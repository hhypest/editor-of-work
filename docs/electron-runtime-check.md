# Проверка хранилища и PDF в Electron

`npm run check:electron` проверяет требование ADR-0021 на настоящем Electron из
lock-файла. Перед запуском выполните `npm ci` и `npm run build`: проверка использует
миграции и preload из собранного desktop, а также бандл UI. На Windows команда запускается непосредственно;
на Linux нужен графический сеанс либо `xvfb-run -a npm run check:electron`.

В отдельной временной папке создаётся вымышленный паспорт. Проверяются создание
схемы, WAL, работа публичного адаптера через Kysely, активация двух редакций,
резервная копия состояния до каждой активации и повторное открытие основной базы.
Проба отказывается работать под обычным Node и не использует
`ELECTRON_RUN_AS_NODE` или флаги включения SQLite. Тестовых ветвей в production
main нет; код пробы собирается отдельно и не входит в поставку.

Процесс ограничен тайм-аутом. Ненулевой код, сигнал, отсутствие корректного отчёта
или несовпадение версии Electron с установленным пакетом означают отказ. После
успеха отчёт с версиями Electron, встроенного Node и SQLite и именами проверок
находится в `test-results/electron-runtime/report.json`. В CI Windows он сохраняется
как артефакт; базы, журналы и данные паспорта не загружаются. Временная папка
удаляется и при ошибке; прежний отчёт удаляется перед новым запуском.

Проверка хранилища доказывает совместимость со встроенным Node Electron. Проверка PDF ниже запускает production preload и Angular-компонент листа. Полный запуск production main с паспортом, визуальные эталоны, переносной exe и приёмка на рабочем ПК остаются в #6/#26/#27.

## PDF А3

Та же команда после обеих сборок запускает скрытое окно с настоящим Angular-бандлом и production preload. Проверка на вымышленной странице сверяет SVG с моделью (геометрия в мм, буквальный текст), отсутствие навигации редактора и Node в renderer. Затем pdf-lib читает результат: ровно одна страница, А3 альбом 420 × 297 мм, встроенные PT Sans и PT Sans Narrow 400/700. Окно должно закрыться до завершения проверки. Временные PDF и данные не публикуются; артефакт CI содержит только числовой отчёт `pdf` вместе с прежними проверками хранилища. Проверка не заменяет эталоны и визуальное сравнение #26.

Production-сборка отключает только `optimization.styles.inlineCritical`: CSS подключается обычным внешним link. Генерируемый Angular скрипт переключения `media=print` блокируется строгой CSP; без этого исправления шрифты предпросмотра/PDF недоступны. Минификация сохраняется; политика `script-src` не ослабляется. Проверка настоящего PDF выявляет и такой сбой загрузки CSS.
