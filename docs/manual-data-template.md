# Шаблон ручных данных

Раздел «Ручные данные» выдаёт книгу с текущими значениями паспорта и принимает
заполненную книгу обратно в черновик редакции. Это часть мастера #21; загрузка
17 форм ЕК АСУИ через интерфейс остаётся следующим шагом.

## Работа в программе

1. В разделе «Паспорт» создайте или выберите черновик. Откройте «Ручные данные»:
   по умолчанию выбран черновик; нужную редакцию можно выбрать из списка.
2. Нажмите «Выдать шаблон» и укажите путь в системном диалоге. Книга содержит
   текущие значения именно выбранной редакции; первая книга содержит только заголовки.
3. Заполните книгу по правилам ниже. Нажмите «Загрузить заполненную книгу» и выберите xlsx.
4. Проверьте число добавлений, изменений и удалений по каждому листу. До подтверждения
   данные и журнал не меняются. Все пять разделов заменяются целиком; удаление всех
   строк листа с сохранёнными заголовками очищает этот раздел.
5. Нажмите «Подтвердить замену ручных данных» или «Отменить загрузку».
   Во время операции и до решения нельзя сменить редакцию. При отсутствии изменений
   данные и журнал сохраняются без перезаписи.

Предпросмотр действует 10 минут, предназначен только для выбранной редакции и
используется один раз. Новая загрузка отменяет прежний предпросмотр. Если основа
паспорта поменялась, заново выдайте книгу и перенесите изменения; после ошибки
записи загрузите книгу заново. Действующие и архивные редакции можно выгрузить,
но нельзя изменить. Обновлённые значения видны при возвращении в раздел «Паспорт».
Кнопка «Обновить список редакций» перечитывает статусы, если они изменились.

## Содержание книги

| Лист                    | Что заполняется                                                                                                         |
| ----------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| Виды работ              | Уникальный код, название, единица, группа, условное обозначение, код «входит в»                                         |
| Периодичность ремонтов  | Код вида ремонта, класс/группа/категория пути, типы рельсов и шпал, пороги в годах и млн т брутто                       |
| Допуски                 | Уникальный код, название, числовое значение, единица, условия применения                                                |
| Пары поездов            | Точное название направления, начало/конец участков как км и м, пары грузовых, пассажирских, пригородных поездов в сутки |
| Нестандартные километры | Точное название направления, номер км, его длина в целых метрах                                                         |

Виды работ имеют группы «текущее», «капитальное», «прочее». Код в «входит в» должен
присутствовать на том же листе и иметь ту же единицу; циклы запрещены. Норма должна
ссылаться на вид работ и существующий класс из характеристик паспорта. Хотя бы
один порог — лет или млн т брутто — заполнен положительным числом. Значения из
«Допусков» сохраняются как справка, ими ничего автоматически не проверяется.
Числа нормативов вводит составитель, программа не заполняет их по умолчанию.

У каждого листа есть необязательные начало и конец действия: пустая граница
означает отсутствие ограничения. Даты принимаются как `дд.мм.гггг` и `ГГГГ-ММ-ДД`,
включая даты Excel. Конец не может быть раньше начала. Числа допускают десятичную
запятую; нулевое количество пар отличается от пустой ячейки. Дробные пары поездов
допускаются как среднесуточное значение.

Координаты и длины км — целые числа. Длина км должна оставлять девять полных
пикетов; остаток относится на пк 10. Участки пар поездов лежат в одной непрерывной
части направления и не перекрываются в пересекающихся периодах. Уменьшение длины
км отклоняется, если ранее сохранённые координаты окажутся за его пределами.

## Выдача, предпросмотр и загрузка

1. Получить основу выбранной редакции через `PassportManualData.manualBasis`.
2. `exportManualTemplate` выдаёт xlsx с текущими значениями через порт
   `ManualDataTemplate` и адаптер `XlsxManualDataTemplate`. Пустая редакция даёт
   только заголовки, без вымышленных нормативов.
3. Заполнить явные значения. Формулы нужно заменить значениями; даже сохранённый
   результат формулы не принимается. Не переименовывать/удалять листы и столбцы.
4. `prepareManualTemplate` проверяет книгу и возвращает команду вместе с числом
   добавлений, изменений и удалений по каждому листу. Ошибка указывает лист,
   исходную строку, в том числе после пропусков, и столбец.
5. `applyManualData` применяет команду одной транзакцией в черновик. Обёртка
   `importManualTemplate` соединяет чтение, проверку и запись программно.
   `manualImportReport` возвращает журнал с именем файла, SHA-256 и числом строк.

Все пять листов заменяются целиком. Для удаления записи удаляют **всю строку**,
а не очищают её видимые ячейки: скрытый идентификатор тоже является частью строки.
Пустой лист с сохранёнными заголовками означает явную очистку этого раздела.
Неизменённая книга не меняет данных или журнала, даже после перестановки строк.
Нельзя удалять скрытые столбцы и лист служебных сведений: они сохраняют ключи и
защищают от загрузки книги поверх более свежих данных.

Если после выдачи книги поменялись ручные данные, направления, длины км или классы,
загрузка просит выдать новый шаблон. Следует перенести в него только свои изменения
видимых значений. Действующие и архивные редакции доступны для чтения, запись в них
запрещена. Новая редакция копирует ручные данные и журнал.

Книги и паспортные данные остаются служебными файлами пользователя. Их не добавляют
в репозиторий и PR. Тесты генерируют книги в памяти только из вымышленных данных.

Читатель допускает файл xlsx до 64 МиБ, до 32 МиБ на распакованную часть и
128 МиБ на все читаемые части книги, включая скрытый лист шаблона; записей ZIP
может быть не более 4096. Проверяются фактический объём и соответствие заголовкам.
Отказ не меняет ручные данные и журнал. Если книга превышает ограничения,
выдайте новый шаблон и перенесите необходимые строки без лишнего оформления.
