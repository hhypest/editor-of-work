# Импорт выгрузок ЕК АСУИ

Мастер доступен в настольной программе в разделе «Импорт выгрузок».
Создайте черновик в разделе «Паспорт», затем выберите его в мастере.
Действующая и архивные редакции защищены от записи.

## Порядок загрузки

| Шаг                   | Формы                                                                                        | Что заменяется                                                           |
| --------------------- | -------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------ |
| 1. Оргструктура       | Подразделения, границы, станции → ПД, станционные пути → ПД                                  | Полный пакет четырёх форм со всеми частями                               |
| 2. Характеристики     | Класс, грузонапряжённость, скорости, рельсы, шпалы и скрепления, балласт                     | Полный набор частей каждой переданной формы; остальные формы сохраняются |
| 3. Станции и переезды | Оси, экспликации путей и стрелок, общие/технические/эксплуатационные данные переездов, ОКАТО | Полный пакет семи форм со всеми частями                                  |

Сначала загрузите оргструктуру: направления нужны для сверки остальных пакетов.
На каждом шаге нажмите «Выбрать формы и все их части». В системном диалоге
выберите относящиеся к шагу файлы xls/xlsx. Форма определяется по заголовкам,
а не по номеру или расширению файла. Одну форму можно выгрузить несколькими
частями; передавайте все части одновременно. Имена файлов должны различаться.

Для веб-выгрузки frameset сохраняйте рядом папку `.files`; выбирайте сам xls,
лист из папки программа прочитает автоматически. Чтение частей за пределами
папки выбранного файла, в том числе через символическую ссылку, запрещено.
Двоичный Excel 97–2003 нужно пересохранить в xlsx; изменения расширения недостаточно.

## Выбор подразделений

На первом шаге мастер показывает ПЧУ и ПД, открытые на дату редакции: начало
действия, родителя, число границ и пересечения с другими подразделениями.
Изначально ничего не отмечено. Отметьте действующие ПЧУ и ПД самостоятельно;
предложения проверки не являются решением. Затем нажмите «Проверить выбранные
подразделения». Другие типы подразделений обрабатываются по существующим правилам
паспорта. Старый столбец «ПД» характеристик не определяет принадлежность участков.

## Предпросмотр и подтверждение

Перед записью показаны файлы, распознанные формы, число прочитанных строк, число
нормализованных строк до и после замены, замечания с исходным местом ошибки.
Количество прочитанных строк включает строки вне периода, а количество к записи —
только подготовленные данные; это разные величины, а не числа добавлений и удалений.
Проверьте предупреждения о нестандартных километрах, пересечениях, названиях переездов
и привязках. Нестандартные длины не применяются автоматически: их вводят через
«Ручные данные», после чего характеристики можно проверить заново.

Кандидаты на исключение станций показаны для проверки и автоматически не исключаются.
Сценарий изменения исключений существует в API; отдельный редактор исключений
в этот шаг не входит.

Нажмите «Подтвердить замену пакета» или «Отменить импорт». Само чтение файлов,
выбор подразделений и предпросмотр не записывают данные и журнал. Каждый пакет
фиксируется одной транзакцией; весь цикл из трёх шагов одной транзакцией не является.
Ошибка следующего шага оставляет ранее принятые пакеты в паспорте.

Сеанс действует 10 минут после чтения файлов. Токен предназначен для выбранной
редакции и используется один раз. Если паспорт изменён после предпросмотра,
подтверждение отклоняется внутри транзакции — выберите файлы и проверьте их заново.
Изменение исходного файла на диске после предпросмотра не меняет уже подготовленную
команду: для применения новой версии файла нужно заново выбрать его.

До решения по предпросмотру и во время запроса переключение шага и редакции заблокировано.
После записи можно перейти к следующему шагу или открыть «Паспорт» для просмотра результата.

## Ошибки выгрузки

Неполный обязательный пакет, неизвестная форма, ошибка ячейки или обрезанная таблица
останавливают подготовку без записи. Обрезанную форму повторно выгрузите частями;
все части формы загрузите одним пакетом. Не дописывайте завершающие теги HTML:
это скроет потерю исходных строк. Сообщение об ошибке указывает файл и, когда возможно,
лист, строку и столбец. Ошибка доступа к диску не раскрывает в IPC абсолютный путь.

Технические ограничения одного шага: не более 1000 файлов и 64 МиБ на файл или
связанный лист. Это ограничения обработки повреждённых/чрезмерных входных данных,
а не нормативы предметной области. Файлы выгрузок, база и отчёты остаются на компьютере.
