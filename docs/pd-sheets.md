# Предпросмотр листов ПД

Откройте раздел «Листы ПД». Кнопка «Открыть план для просмотра» читает сохранённый `*.ppr.json` через системный диалог. Поддерживаются прежние версии формата с существующими миграциями. Просмотр не меняет файл, текущий редактируемый план, его путь сохранения и автокопию. «Использовать текущий план» получает актуальное состояние из main. Импорт исходного JSON HTML-прототипа и редактирование плана подключаются в #24.

Выберите ПД, масштаб схемы и страницу. Масштаб просмотра изменяет только размер на экране. Источник — срез редакции внутри плана: новые изменения базы паспорта не меняют старый план. На листе показаны год, ПД и ПЧУ, гриф из плана, редакция, масштаб, условные обозначения.

## Ряды и выноски

Каждая часть протяжения ПД рисуется отдельно, разрывы не соединяются. Длина ряда учитывает таблицу нестандартных километров. На концах неполных рядов подписываются соседние ПД с точной общей границей. Если соседа нет, выводится «Вне действующих ПД» либо «Граница направления»; сосед через разрыв не угадывается.

Серые отрезки и отметки показывают работы в пределах ряда. У работ с признаком выноски есть номер строки ведомости, название, доля объёма в ПД и исходное описание места. Участок работы обрезается только графически по границе ряда; текст места сохраняется. Объём в повторной выноске относится ко всему ПД, а не к странице. Полная работа с примечанием остаётся в ведомости один раз.

Выноски размещаются в свободных полосах. Если четырёх полос не хватает, ряд повторяется с подписью «выноски (продолжение)». Прямоугольники не пересекаются. Текст свыше шести строк отклоняется с объяснением, без обрезки. Станционные работы показаны в ведомости ПД станции; координаты осей отсутствуют в нынешнем формате среза плана и не выдумываются.

## Таблицы

План текущего содержания, капитальные и прочие работы используют существующий расчёт Планирования: доли по ПД, правило «входит в», ручной план (`*`) и потребность. Показатели этого шага — длина главных путей ПД в метрах и число работ. Другие пользовательские показатели и таблицы по областям относятся к #24; их значения не подставляются автоматически.

Высота ячейки определяется переносами PT Sans. Таблица продолжается на новом А3 с заголовком и названиями столбцов. Шрифт не уменьшается ниже 2,5 мм. Если одна строка не помещается на листе, выдаётся ошибка с названием таблицы. Выход за бумагу и скрытая потеря строк не допускаются.

Документ ограничен 200 листами. Есть предварительный лимит сложности расчёта и размера ответа (20 МиБ), чтобы большой план не блокировал интерфейс. Ошибка оставляет исходный план и файлы прежними. PDF добавляется в #25, снимки Windows и сравнение с прототипом — в #26.
