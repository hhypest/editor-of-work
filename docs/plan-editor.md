# Редактор годового плана: первый шаг #24

Раздел «Годовой план» редактирует сохранённый файл `*.ppr.json` либо проект HTML-прототипа. Создание нового плана из редакции базы паспорта, дополнительные показатели, подрядные работы, ИССО, ЗП и настройки листов ещё разрабатываются. Этот шаг не закрывает #24 целиком.

## Открытие и импорт

«Открыть план» вызывает системный диалог и читает файл прежнего формата v1/v2 через существующие миграции. Для JSON HTML-прототипа раскройте блок импорта, укажите номер и дату редакции, выберите проект. Виды работ берутся из его каталога; нормативы программа не подставляет. Неперенесённые поля остаются в исходном архиве плана; отчёт доступен внизу экрана.

План использует свой срез паспорта. Изменение текущей базы не меняет старый файл. Область «Дистанция», ПД или станция отбирает список работ и таблицы; фильтр ничего не удаляет. В списке указан полный объём работы, в таблицах — доля выбранной области по существующим правилам расчёта.

Если найдена автокопия, сначала выберите восстановление или явный отказ от неё. До этого редактор не меняет план и не перезаписывает найденную копию. Отказ удаляет только файл автокопии после подтверждения; восстановление оставляет основной файл прежним до сохранения.

## Работы и таблицы

Выберите вид работ, привязку и направление. В поле места допустимы, например, `227 км пк 4 – 228 км пк 10; 234+300`. Подсказка показывает разбор и длину, синтаксическая ошибка — позицию прямо под полем. При применении дополнительно проверяются протяжение направления, станция, номер пути или стрелки. Километры нестандартной длины берутся из среза плана.

Пустой объём считается по участкам только для единицы «км». Для остальных единиц он обязателен. Ноль сохраняется как ноль; десятичная часть вводится через запятую или точку. «Применить работу» меняет план в памяти; запись файла выполняет «Сохранить». «Отменить ввод» отменяет только заполнение формы. Удалённая работа восстанавливается общей отменой.

В таблицах текущего содержания, капитальных и прочих работ можно задать ручной план и потребность. Пустой ручной план возвращает расчёт, пустая потребность удаляет значение. «Применить значения таблиц» проверяет весь введённый пакет: при ошибке не применяется ни одна его строка; успешный пакет отменяется одним шагом. Ручной план помечен `*`. Гриф утверждения редактируется отдельным блоком и тоже входит в историю.

## Сохранение и отмена

- **Ctrl+S** применяет незавершённый ввод работы, таблиц и грифа, затем сохраняет план. При ошибке запись файла не выполняется, введённый текст остаётся на экране.
- **Ctrl+Shift+S** выбирает другой путь. Отмена диалога и ошибка записи сохраняют прежний путь и историю.
- **Ctrl+Z / Ctrl+Y** отменяют и повторяют изменения плана, до 200 шагов. В поле ввода эти сочетания остаются нативной отменой текста. Перед общей отменой незавершённый ввод нужно применить либо отменить.
- **Ctrl+P** пока сообщает, что PDF недоступен, и не печатает окно редактора. Экспорт относится к #25.

Сохранение не сбрасывает историю. После отмены сохранённой правки план снова отмечен изменённым, после её повтора — сохранённым. У нового импортированного проекта нет пути: первое сохранение выбирает файл и включает минутную автокопию. Ошибки автокопии видны при следующем обновлении состояния или действии с планом.

При замене плана незавершённый ввод и несохранённые изменения требуют выбора: сохранить, продолжить без сохранения или остаться. Отмена системного диалога оставляет ввод прежним. Незавершённая форма сохраняется в памяти при переходе в другой раздел. При закрытии окна программа предупреждает о несохранённых данных.

## Границы готовности

Редактор этого шага не зависит от незавершённого PR листов ПД. Предпросмотр текущего листа и проверка времени его перерисовки менее 200 мс подключаются после #71; фильтр пока задаёт область плана, а не физическую страницу. Дополнительные таблицы и создание плана из базы остаются в #24, PDF — #25. Формат файла не меняется, архив прототипа сохраняется.
