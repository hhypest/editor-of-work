# Импорт проекта прототипа — задача #12

Импорт принимает JSON, сохранённый HTML-прототипом кнопкой «Сохранить».
Состав работ: перенос метаданных года и грифа, направлений с разрывами,
ПД, станций и привязок работ, каталога видов, ручных значений и потребности.
Дробные километры переводятся в пары «км, м»; нецелые метры требуют исправления.
Нормативы берутся только из входного каталога, без встроенных значений.

Раскладка станций, оформление, дополнительные таблицы и неизвестные поля
сохраняются в снимке исходного JSON. Отчёт перечисляет поля, для которых ещё
нет редактируемой модели. Новая программа не удаляет работы и не исправляет
ошибки молча: при ошибке выдаётся отчёт и весь импорт отклоняется.

Формат плана v2 добавляет снимок прототипа и отчёт импорта, а также позволяет
сохранить принадлежность линейной работы к станции. Старые планы v1 открываются
через миграцию; образец v1 остаётся в тестах.

Проверка: только вымышленные проекты той же структуры, все типы мест и объёмов,
перенос раскладки без изменений, сохранение и повторное открытие, ошибки
координат и ссылок, неизвестная версия. HTML-прототип и пример PDF остаются
локальными справочными материалами и в репозиторий не добавляются.
