# Критерии выпуска 0.5.0

Выпуск 0.5.0 даёт составителю паспорт дистанции из выгрузок ЕК АСУИ и годовой план с листами ПД в PDF А3. Здесь перечислено, что должно быть верно до выпуска; что уже сделано — в [текущем состоянии](../current-state.md), порядок работ — в [дорожной карте](../roadmap.md). Выпуск собирается и публикуется только вручную владельцем репозитория (#27).

## Функциональный объём

- Паспорт: импорт 17 форм с выбором подразделений, предпросмотром и подтверждением; редакции; шаблон ручных данных с типовым перечнем; отчёт о ремонтах.
- План: создание из редакции, работы, план и потребность, гриф, показатели, ожидаемые показатели, таблица «Показатели» на 01.01 двух лет, перечни подрядных работ, ИССО и ЗП, настройки листов ПД, импорт проекта прототипа включая перечни.
- Листы: общая схема А3, листы ПД; PDF текущего, выбранных и всех листов ПД.
- Вне объёма 0.5.0: листы станций, схемы дистанции, административное деление, переход на новый год.

## Автоматические проверки

Должны проходить на последнем коммите выпуска:

- `npm run check` на Ubuntu и Windows в CI;
- `check:electron` на Windows: хранилище паспорта и PDF в настоящем Electron;
- сквозной сценарий production-сборки (часть #37, пункты 3–9 приёмки на вымышленных данных) и эталонные снимки листов (#26) на Windows;
- тесты открытия файлов плана всех прежних форматов (v1–v7) и отказ записи файла более новой версии.

## Приёмка на рабочем ПК

Проверяет владелец на Windows 10 или 11 x64 без прав администратора. Пункты 1–12 выполняются на вымышленном комплекте, пункты 13–15 — на реальных выгрузках, которые не покидают ПК. В протокол записываются только результаты и версии, без данных дистанции, путей пользователя и снимков экрана с реальными данными.

## Поставка

- Один переносной exe, собранный вручную из тега; SHA-256 опубликован вместе с ним.
- Версия `0.5.0` в `package.json`, CHANGELOG перенесён из «Не выпущено» в раздел выпуска.
- Программа не обращается к сети; в сборке нет телеметрии и автообновления.

Выпуск 0.5.0 закрывает #6, #21, #24–#27 и эпик #28.
