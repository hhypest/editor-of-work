# Проверка интерфейса на рабочем ПК — 23.10.2026

Проверка выполнена через настоящий интерфейс Windows, системные диалоги и клавиатуру.
Запускалась локальная desktop-сборка main после PR #85 и затем сборка с исправлением
резервного распознавания горячих клавиш. Это ограниченная проверка редактора и PDF,
а не завершение приёмки #21, #24–#27 или выпуск portable.

## Среда и данные

- Windows 11 Pro, сборка 26300, Electron 44.9.0; сборка проекта под Node 24.22.1.
- Production-бандл Angular, настоящий main/preload и штатная политика безопасности.
- Окно 1400 × 900 и развёрнутое окно 2560 × 1392.
- Только вымышленная фикстура v5: направление 10+000–11+000, длина км 964 м,
  один ПД, одна станция и один вид работ; ручной план 2, потребность 0,
  показатель −1,25 и скрытая ведомость. Рабочие выгрузки пользователя не открывались.
- База и тестовые планы находятся локально в игнорируемой папке `private-data/`;
  в Git нет файлов плана, PDF и снимков рабочего стола.

## Найденная и исправленная ошибка

После исправления Ctrl+P для готового листа ПД открыл штатный диалог и записал
второй PDF. Повторная проверка подтвердила одну страницу А3, встроенные шрифты
и обновлённый расчёт 0,7 км; остальные ручные значения сохранились.

При вводе через службы Windows событие приходило с пустым `KeyboardEvent.code`,
`key: 'ы'` и `ctrlKey: true`. Проверка только `code === 'KeyS'` пропускала сохранение.
Это воспроизведено в настоящем renderer временной диагностикой без записи текста
полей; диагностический код удалён из итогового изменения.

Если `code` пуст или равен `Unidentified`, редактор теперь распознаёт S/Ы, P/З,
Z/Я и Y/Н через `key`, включая верхний регистр. Известный физический код имеет
приоритет. Ctrl+Alt не перехватывается; отмена/повтор в полях остаются нативными.
Компонентные тесты дополнительно проверяют обе раскладки, модификаторы,
единственный запрос PDF и игнорирование посторонних сочетаний.

## Проверка сохранённого PDF

PDF кнопки содержит одну страницу 1191,12 × 841,92 pt
(420,20 × 297,01 мм), А3 альбом. Проверены структура и извлечённый текст,
страница отрисована Poppler и осмотрена: рамка, выноска, таблицы и подписи
без видимого наложения или обрезки. Шесть встроенных подмножеств PT Sans /
PT Sans Narrow обслуживают кириллицу и числа. На листе сохранены расчёт 0,5,
ручной план 2*, потребность 0, длина 964 м и показатель −1,25;
скрытая ведомость отсутствует. Масштаб просмотра 50% не меняет А3 в файле.

420,20 × 297,01 мм, 8 встроенных подмножеств шрифтов, `svgMatches: true`.
