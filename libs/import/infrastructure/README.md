# import-infrastructure

`@eow/import/infrastructure` · контекст «Импорт выгрузок (антикоррупционный слой)» · теги `type:infrastructure`, `scope:import`

Инфраструктура: реализации портов (адаптеры). Не импортирует UI.

`importPrototype` принимает JSON, сохранённый HTML-прототипом, ссылку на редакцию
и генератор идентификаторов. Каталог видов берётся из JSON; для старого файла
без каталога его нужно передать отдельно из прототипа или редакции паспорта.
Встроенных нормативов нет. Внутренние идентификаторы видов остаются ключами плана.

Разбор возвращает опубликованный `PrototypeTransfer` слоя приложения Импорта,
без зависимости от домена Планирования. Composition root main передаёт его в
`buildImportedPlan`: фабрики Планирования проверяют все ссылки и инварианты.
Текущий документ заменяется только после успешной проверки всего проекта.

Импорт не исполняет HTML и не читает часы. Ошибка поля, координаты, ссылки или
работы отклоняет весь проект; ни одна работа не отбрасывается молча. Раскладка
станции переносится в типизированный `legacyLayout` среза и также сохраняется
без изменений в снимке исходного JSON. Редактор и отрисовка относятся к #29;
прочие неподдержанные поля перечислены в отчёте и тоже остаются в снимке.
Подробности и ограничения — [docs/prototype-import.md](../../../docs/prototype-import.md).

## Вымышленные выгрузки для тестов

`src/lib/testing/passport/` собирает вымышленные выгрузки всех 17 форм паспорта (ADR-0008):
12 «веб-страничных» xls, 3 книги переездов и 2 отчёта BEx, плюс одну форму в варианте frameset.
Шапки, атрибуты ячеек, объединения и закрепления повторяют настоящие формы, а данные
придуманы: направления, станции, подразделения и ФИО взяты из `model.ts`. В данных
есть особенности, которые обязан выдержать импорт: нестандартные километры, прежние
и новые коды ПД, «Нет данных», «-1», «-----», ликвидированная станция, переезд
с неверной станцией в названии, длина отрезка, не сходящаяся с координатами.

Тесты получают файлы в памяти через `generatePassportFixtures()`; в Git фикстуры
не хранятся. `npm run fixtures [папка]` записывает их на диск (по умолчанию
`tmp/fixtures/passport`), чтобы открыть в Excel.
